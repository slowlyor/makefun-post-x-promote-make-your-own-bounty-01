Quote or link make.fun's make-your-own-bounty post in a post of your own on X; places go by your post's replies, reposts and quotes, and the top 50 share $250.

This repository holds the entry: `main.ts` copies `POST.json` (the address of the X post, filled in after the user posts it) to the output directory, `post-photo.png` is the post's own original photo, and `POST-DRAFT.txt` is the draft text of the post.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
